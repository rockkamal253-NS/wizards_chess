# Project rule (always on)

Before doing anything, read `AGENTS.md` and `docs/PROGRESS.md` in the repo root. They are the project memory. Follow the session protocol in `AGENTS.md`: start with `/start-session`, finish with `/end-session`.

Do not re-read the whole codebase; use the file map in `AGENTS.md`. Never weaken a test to make it pass. Run `npm run test:all` before every commit. Use the `ponytail` skill (simplest working solution) for coding tasks when it is available.
