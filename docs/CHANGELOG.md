# Changelog

All notable changes to Wizard's Chess will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-25

### Added
- Gothic cathedral 3D environment with PBR lighting and shadows.
- Chess engine integration with AI difficulty levels (Novice, Adept, Master) and 2-player mode.
- Clock support (None, 5m, 10m).
- Replay move chronicle and PGN/FEN import/export dialogs.
- Automated browser E2E test suite with Playwright and visual regression testing.
- UI footer displaying application version (`v0.1.0`).
- Living documentation, session protocols, and CI test pipeline with Node.js 22.
